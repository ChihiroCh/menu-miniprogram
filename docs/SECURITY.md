# 依赖与运行边界

本工程包含真实身份和家庭权限边界，但尚未完成上线验收。不要将开发服务器或模拟登录暴露到公共网络。

依赖审计中，已移除受影响的通用静态文件服务插件，改为仅接受明确图片文件名的本地图片路由，并将服务端 Zod 校验库升级至修复版本。

uni-app 官方构建链绑定 Vue 3.4 和 Vite 5；审计仍会报告其传递依赖（如 i18n、SSR、图像处理和开发服务器）以及 Prisma CLI 的部分依赖。不能将 `npm audit fix --force` 建议的早期 uni-app 版本视为安全升级，强制切换会破坏双端兼容。

本项目不提供 SSR、不处理用户提供的国际化模板或 ZIP 包。生产只部署构建后的 H5 静态文件和 API，不启动 Vite 开发服务器。开发服务器默认仅监听回环地址，并限制允许的跨来源请求。发布前仍应按最新官方 uni-app 兼容矩阵复核上述告警，升级后重跑双端构建和核心流程；这些隔离措施不代表审计告警已全部消除。

生产要求 HTTPS、关闭模拟登录、S3 对象存储。会话令牌在数据库中以 SHA-256 摘要保存；网页使用 HttpOnly Cookie，小程序使用可撤销令牌。所有家庭接口均检查成员身份，管理员操作与所有者操作分别鉴权。

图片 URL 为持有链接即可读取的资源，适用于普通菜品照片；不要上传敏感个人文件。若后续需要私密相册，应单独实现授权下载和短期签名 URL。
